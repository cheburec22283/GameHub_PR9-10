В учебных примерах RabbitMQ адрес и учётные данные задаются через окружение. Из корня проекта запустите брокер командой `docker compose up -d rabbitmq`, установите зависимости из `requirements.txt` и укажите `RABBIT_USER=gamehub`, `RABBIT_PASSWORD=local-only` для локального Compose. Затем из папки выбранного варианта запустите `python consumer.py` и в другом терминале с теми же переменными выполните `python producer.py`.
